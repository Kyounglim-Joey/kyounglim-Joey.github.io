# 프로필 사진 · About 갤러리 — Google Drive 연동 가이드

**사진 원본을 GitHub 저장소에 올리지 않고** 사이트에만 표시하는 방법입니다.
- Drive 폴더에 `profile.jpg` → 왼쪽 프로필 사진 (정사각형 600×600으로 자동 변환)
- 그 외 사진 → About 페이지 맨 아래 갤러리

## 동작 방식

```
[내 Google Drive 폴더] ──(GitHub Actions, 하루 1회 + 수동 실행)──▶ 사진 다운로드
     → 리사이즈 · EXIF/GPS 제거 (sharp) → 사이트에 포함해 배포 → About 페이지 맨 아래 캐러셀
```

- 방문자의 브라우저는 Google에 접속하지 않습니다. 사진은 내 사이트(github.io)에서 바로 제공됩니다.
- **Drive 폴더는 비공개로 유지**합니다. 읽기 전용 서비스 계정 하나에만 공유합니다.
- 새 사진은 **다음 자동 빌드(매일 03:17 KST)** 에 반영됩니다. 바로 반영하려면 Actions에서 **Run workflow**를 누릅니다.
- 화면에는 데스크톱 3장, 태블릿 2장, 휴대폰 1장씩 보이고, ‹ › 버튼·스와이프·키보드 방향키로 넘길 수 있습니다. 사진을 누르면 큰 이미지가 새 탭에서 열립니다.

### 실시간 연동(브라우저에서 바로 Drive 읽기)을 쓰지 않은 이유

| 문제 | 설명 |
|---|---|
| 폴더 공개 필요 | Drive 폴더를 "링크가 있는 모든 사용자"로 공개해야 함 |
| API 키 노출 | 페이지에 Google API 키를 넣어야 함 |
| 방문자 정보가 Google로 전송 | 방문자 브라우저가 Google 서버에 직접 요청함 → Privacy 정책, CSP와 충돌 |
| 안정성 | Drive 이미지 직접 링크는 공식 지원 방식이 아니라 언제든 깨질 수 있음 |

## 설정 (최초 1회, 약 15분)

### 1. Drive 폴더 만들기
1. Google Drive에서 새 폴더를 만듭니다 (예: `portfolio-photos`).
2. 폴더를 열면 주소창이 `https://drive.google.com/drive/folders/1AbCdEf...XyZ` 형태입니다.
   → `folders/` 뒤의 문자열이 **Folder ID**입니다. 복사해 둡니다.

### 2. Google Cloud에서 Drive API 켜기
1. https://console.cloud.google.com 에 같은 Google 계정으로 로그인합니다.
2. 상단 프로젝트 선택 → **새 프로젝트**를 만듭니다. 이름은 예를 들어 `portfolio-photos`로 합니다.
3. 왼쪽 메뉴 **API 및 서비스 → 라이브러리**에서 **Google Drive API**를 검색하고 **사용**을 누릅니다.
   - 무료입니다. 결제 정보 등록을 요구하지 않는 범위에서 사용합니다.

### 3. 서비스 계정(봇 계정) 만들기
1. **IAM 및 관리자 → 서비스 계정 → + 서비스 계정 만들기**를 누릅니다.
2. 이름을 `portfolio-photos`로 입력하고 **만들고 계속하기**를 누릅니다.
   - 역할(Role) 부여 단계는 **아무것도 선택하지 않고 건너뜁니다.** 프로젝트 권한이 필요 없습니다.
3. **완료**를 누르면 목록에 `portfolio-photos@<프로젝트ID>.iam.gserviceaccount.com` 이메일이 생깁니다. 복사해 둡니다.
4. 서비스 계정을 클릭하고 **키 → 키 추가 → 새 키 만들기 → JSON → 만들기**를 누르면 `.json` 파일이 다운로드됩니다.
   - 이 파일은 **비밀번호와 같은 비밀 정보**입니다. 저장소에 올리거나 메신저로 보내지 마세요.
   - "키 생성이 조직 정책으로 차단됨"이 뜨면 회사·학교 계정입니다. **개인 Gmail 계정**으로 진행하세요.

### 4. Drive 폴더를 서비스 계정에 공유
1. 1단계 폴더에서 **공유**를 누릅니다.
2. 3단계의 서비스 계정 이메일을 입력하고 권한을 **뷰어**로 선택합니다.
3. "이메일 알림 보내기"는 해제하고 **공유**를 누릅니다.
   - 서비스 계정은 **이 폴더만** 읽을 수 있습니다. 내 Drive의 다른 파일에는 접근하지 못합니다.

### 5. GitHub에 등록
저장소 → **Settings → Secrets and variables → Actions**에서 두 가지를 등록합니다.

| 탭 | 이름 | 값 |
|---|---|---|
| **Secrets** → New repository secret | `GDRIVE_SERVICE_ACCOUNT_KEY` | 다운로드한 JSON 파일을 메모장으로 열어 **내용 전체**를 복사해 붙여 넣기 (`{` 부터 `}` 까지) |
| **Variables** → New repository variable | `GDRIVE_FOLDER_ID` | 1단계의 Folder ID |

- 등록이 끝나면 PC의 JSON 파일은 삭제하거나 비밀번호 관리자에 보관합니다.
- Secrets 값은 한 번 저장하면 다시 볼 수 없고, 빌드 로그에도 `***`로 가려집니다.

### 6. 첫 실행과 확인
1. Drive 폴더에 사진을 2~3장 올립니다.
2. **Actions → Deploy to GitHub Pages → Run workflow**를 실행합니다.
3. 실행 로그의 **Sync gallery photos** 단계에 `Drive: 3 image(s) in folder`, `gallery: 3 photo(s) written`이 보이면 성공입니다.
4. 사이트 **About** 페이지 맨 아래에서 사진을 확인합니다.

## 평소 사용법

| 하고 싶은 일 | 방법 |
|---|---|
| 프로필 사진 | Drive 폴더에 **`profile.jpg`** 이름으로 업로드 (교체 시 같은 이름으로 새로 올리고 이전 파일 삭제) |
| 사진 추가 | Drive 폴더에 업로드 → 다음 날 자동 반영. 급하면 Run workflow |
| 사진 삭제 | Drive에서 삭제(휴지통) → 다음 빌드부터 사라짐 |
| 순서 정하기 | **파일명 순서**로 표시됩니다. `01_`, `02_`처럼 앞에 번호를 붙이세요 |
| 캡션(설명) | Drive에서 파일 → **파일 정보 → 세부정보**의 설명란에 입력합니다. 설명이 없으면 캡션 없이 표시되고, 대체 텍스트(alt)는 파일명에서 만들어집니다 (`01_security_meetup.jpg` → "security meetup") |
| 개수 제한 | 최대 40장 |

### 파일 형식
- **JPG, PNG, WebP**를 지원합니다.
- 아이폰 기본 형식인 **HEIC는 지원하지 않습니다** (해당 파일은 건너뛰고 로그에 표시됨).
  - 아이폰 **설정 → 카메라 → 포맷 → 높은 호환성**으로 바꾸거나, JPG로 변환해서 올리세요.
- 원본 크기는 상관없습니다. 자동으로 800px(목록용)과 1800px(확대용) WebP로 변환됩니다.

## 보안·개인정보 설계

| 항목 | 구현 |
|---|---|
| 최소 권한 | 서비스 계정 범위는 `drive.readonly`이고, 공유받은 폴더 하나만 접근 가능 |
| 비밀값 격리 | 키는 GitHub **Secret**에만 저장. 워크플로에서도 사진 동기화 단계에만 전달하고, 사이트 빌드 단계와 그 의존성에는 전달하지 않음 |
| 메타데이터 제거 | 모든 사진을 다시 인코딩해 **EXIF 전체(GPS 위치, 카메라 기종·시리얼, 촬영 시각)를 제거**. 회전 정보만 반영 |
| 실패 시 안전 | Drive 동기화가 실패하면 빌드를 중단해서, 사진이 빈 사이트가 배포되지 않고 직전 배포가 유지됨 |
| 방문자 프라이버시 | 사진을 내 도메인에서 제공하므로 방문자 정보가 Google로 가지 않음 |

### 운영할 때 주의할 점
- **다른 사람이 나온 사진은 공개 전에 동의를 받으세요.** 회사 내부 공간, 화면, 출입증, 문서가 찍힌 사진도 올리지 않는 것이 안전합니다.
- 서비스 계정 키는 1년에 한 번 정도 교체하세요. 새 키를 만들어 Secret을 갱신한 뒤, Cloud Console에서 이전 키를 삭제합니다.
- 키가 유출됐다고 의심되면 Cloud Console → 서비스 계정 → 키에서 **즉시 삭제**합니다. 이 키로 할 수 있는 일은 해당 폴더 읽기뿐입니다.
- GitHub은 **60일 동안 저장소 활동(커밋)이 없으면 예약 실행(schedule)을 자동으로 끕니다.** 안내 메일이 오면 Actions 탭에서 다시 켜거나 아무 커밋이나 push 하세요.

## 내 PC에서 미리보기
저장소의 `photos/` 폴더에 같은 사진을 넣고 `npm run dev`를 실행하면 내 PC에서만 반영된 모습을 볼 수 있습니다.
이 폴더의 사진은 `.gitignore`로 제외되어 **commit/push 되지 않습니다** (`photos/README.md` 참고).

## 문제 해결

| 로그 메시지 | 원인 · 해결 |
|---|---|
| `token request failed: HTTP 400 invalid_grant` | Secret에 JSON이 일부만 들어감 → 전체를 다시 붙여 넣기 |
| `files.list failed: HTTP 403 ... Drive API has not been used` | 2단계의 Drive API 사용 설정 누락 |
| `Drive: 0 image(s) in folder` | 4단계 공유 누락, 또는 Folder ID 오타 |
| `skip "xxx.heic": cannot decode` | HEIC 파일 → JPG로 변환 |
| Sync 단계는 성공했는데 사진이 안 보임 | About 페이지를 Ctrl+F5로 새로고침 |
